## 補足

- N-008〜N-010 のテスト用 xlsx は、削除前の同梱 `excel2md/v2.1.1/tests/fixtures/` のフィクスチャを退避して使用した
- excel2md v2.1.1（同梱）→ v2.3.0（PyPI）の変換結果の比較は PR #31 に記載。差分は「印刷領域（未設定時は使用範囲）の外に置かれた画像のリンクが出力されなくなる」1 点のみ（上流 v2.2.1 の意図的な修正 [excel2md#14](https://github.com/elvezjp/excel2md/issues/14)）
- E-001 / E-002 は 0.2.0 で修正済みのパストラバーサル（GHSA-f63v-8r92-h4r7）が、ルート構成への移行後も有効であることの回帰確認
